
# La Casa di LO - Webapp per la Casa Vacanze

Questa webapp è stata sviluppata per presentare e gestire le prenotazioni per La Casa di LO, una bellissima casa vacanze situata a Monopoli.

## Caratteristiche

- **Presentazione della casa**: Descrizione dettagliata con foto e amenities
- **Sistema di prenotazione**: Form per richiedere prenotazioni

## Sito Live

🌐 **Visita la webapp:** [https://fraarv.github.io/La-Casa-di-LO/](https://fraarv.github.io/La-Casa-di-LO/)

L'applicazione è deployata automaticamente su GitHub Pages tramite GitHub Actions.

## Esegui Localmente

**Prerequisiti:** Node.js

1. Installa le dipendenze:
   `npm install`
2. Avvia l'app:
   `npm run dev`

## Deploy

L'app può essere deployata su GitHub Pages o qualsiasi hosting statico.

1. Build dell'app:
   `npm run build`
2. Deploy:
   `npm run deploy`
